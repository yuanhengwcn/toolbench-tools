Why browser-based tools

Most online utilities send whatever you paste to a server, process it there, and send the result back. That is convenient for the developer building the site, but it means your API keys, customer records and configuration files travel across the network and sit in someone else's logs.

Every tool here is implemented in plain JavaScript and runs inside your own browser tab. You can disconnect from the internet after the page loads and the tools keep working. There is no analytics script watching what you type, and no account to create.

What you get

  • Nothing leaves your machine. Input is processed in memory and discarded when you close the tab.
  • No signup or usage caps. There is no account system, no rate limit and no paywall.
  • Works offline. Once loaded, the page needs no network access.
  • Keyboard friendly. Every tool supports standard shortcuts, and the search box opens with /.

What is coming next

A SQL formatter, a cron expression parser, a YAML↔JSON converter, and client-side JWT signature verification using a key you supply locally. If a tool you need is missing, tell me what it is — requests genuinely shape the roadmap.
